Module réseau

Objectif : Mutualiser le réseau dans un module appelé deux fois.

  1. Créez modules/network : déplacez VNet, sous-réseaux, NSG et règles.
  2. Définissez les variables d’entrée et les outputs (vnet_id, subnet_ids).
  3. Appelez le module deux fois : dev (10.10.0.0/16) et prod (10.20.0.0/16).
  4. Relancez init puis plan : combien de ressources vont être créées ?
  5. Affichez les outputs des deux appels, puis apply.

Bonus : remplacez les CIDR en dur par cidrsubnet().

Bonus : une VM dans le sous-réseau

Objectif : Déployer une machine virtuelle configurée par templatefile.

  1. Créez azurerm_network_interface dans snet-app, sans IP publique.
  2. Ajoutez azurerm_linux_virtual_machine en Standard_D2as_v6.
  3. Passez un cloud-init généré avec templatefile.
  4. Vérifiez dans le portail, puis détruisez la VM.

Bonus : ajoutez une IP publique et testez l’accès, puis retirez-la.
