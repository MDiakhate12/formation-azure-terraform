State

La mémoire de Terraform

  • Il relie chaque bloc du code à une ressource réelle (son identifiant Azure)
  • Le plan compare le code, le state et l’état réel
  • Par défaut, c’est un fichier local : terraform.tfstate
  • Il peut contenir des valeurs sensibles en clair

À retenir

Ne commitez jamais un state : il peut contenir des secrets en clair.

State

Le verrouillage

  • Pendant un plan ou un apply, Terraform pose un bail sur le blob du state
  • Un second apply échoue : « Error acquiring the state lock »
  • Le verrou disparaît à la fin de l’opération
  • terraform force-unlock <ID> : dernier recours, seulement si plus personne n’écrit

Réponse à la question

Le bail du blob empêche deux écritures simultanées sur le même state.
